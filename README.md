# Pervigil

*Vigilat dum dormis* — it keeps watch while you sleep.

An AI agent that trades ten tokenized US stocks on Bitget (rTokens) **only while the US cash market is closed**,
explains every decision in one sentence, and is flat again 15 minutes after the open. It comes with a proving
ground that measures whether the agent beats simple fixed rules. Paper trading only.

Bitget AI Base Camp Hackathon S2 · Agentic Trading · Open Theme.

- **Live site:** https://milliebanned.github.io/pervigil/ (no login)
- **Docs:** https://milliebanned.github.io/pervigil/guide.html

## Run records

| Record | File | What is in it |
|---|---|---|
| Live paper-trading log | [`logs/paper_log.jsonl`](logs/paper_log.jsonl) | Every live decision since 2 Oct 2026: time, what the agent saw, its reason, what the risk layer allowed, fills and account equity. Appended by the hourly run. |
| Live trades | [`logs/trades.csv`](logs/trades.csv) | One row per live fill: time, instrument, direction, price, quantity, fee, realized P&L, balance after, balance change. Rewritten after every run. Empty while the agent has stayed out. |
| Replay trades | [`results/trades.csv`](results/trades.csv) | The same columns for all 50 fills of the 55-night replay (33 entries, 15 exits after the open, 2 stops). |
| Replay results | [`results/agent_run0.json`](results/agent_run0.json), [`results/scorecard.json`](results/scorecard.json) | Every replayed decision, and the scorecard against the fixed rules. |
| Morning notes | [`logs/notes/`](logs/notes) | The note written for the human after each session. |

The replay trades are generated by code, not by hand: `python -m pervigil.trades replay` runs the replay engine again
with the agent's recorded decisions and checks that every night ends on the saved result before writing the file.

## Results (replay)

55 closed-market sessions (overnight and weekend, 17 Jul – 2 Oct 2026) on Bitget 15-minute candles, starting from
10,000 USDT, with a 0.10% fee and 0.05% slippage per side. Decisions by Qwen 3.8 Max.

| Policy | Return | Sharpe | Max drawdown |
|---|---|---|---|
| **Pervigil** | **+5.80%** | 4.32 | −0.30% |
| Always follow the move | +3.40% | 3.32 | −0.48% |
| Do nothing | 0.00% | — | 0.00% |
| Always bet against the move | −4.55% | −5.35 | −4.67% |

- Traded on 14 of 55 nights and won 10 of them. 0 of its 33 proposals broke a risk limit. 2 position stops fired.
- The same opening decision came out 98.9% identical across three passes.
- **Caveat:** most of the gain comes from four earnings nights, through one rule that was added after looking at
  this data. The earlier runs (−0.85%, then +0.27%) are kept in [`results/archive/`](results/archive) and shown on the site.

## How it works

1. **Sense.** Every six hours while the market is closed, the agent sees each stock's move since the 4pm ET close,
   that move divided by the stock's normal day, Bitcoin's move over the same window, earnings dates and headlines.
2. **Decide.** Qwen returns a target weight and a one-line reason for each stock. Staying out is allowed.
3. **Risk layer.** Hard limits the model cannot override: 20% per stock, 60% in total, no new risk in the last
   30 minutes before the open, a −3% stop per position and a −2% stop per session. Every blocked proposal is logged.
4. **Execute.** Paper fills at Bitget prices with fees and slippage. With a demo key, each position is also placed
   as an order on Bitget's demo exchange and its order id is logged.
5. **Flatten.** Everything is closed 15 minutes after the open, and a morning note is written.

On the site, the **Live desk** shows Bitget prices for the ten stocks, how big each move is against a normal day, and
the agent's latest call on each. **Ask Pervigil** lets anyone ask why it made a call. Qwen answers from the agent's own
decision log, through a Cloudflare Worker ([`ask/`](ask)) that keeps the model key off the page.

## Run it

Python 3.12, standard library only.

```
cp .env.example .env                 # any OpenAI-compatible endpoint; demo and AgentKey keys are optional
python -m pervigil.data              # download / refresh candles
python -m unittest discover tests
python -m pervigil.replay rules      # the fixed-rule baselines
python -m pervigil.replay agent      # the agent (model answers are cached in data/llm_cache)
python -m pervigil.replay consistency 2
python -m pervigil.replay lab        # every rule the site's "Beat the agent" controls can reach
python -m pervigil.scorecard
python -m pervigil.trades            # results/trades.csv and logs/trades.csv
python -m pervigil.live              # one live cycle
python -m pervigil.site              # build docs/index.html
```

## Where things are

- `pervigil/` — the agent, risk layer, paper book, replay, scorecard, trade export and site builder.
- `data/candles/` — the frozen 15-minute candles the replay uses. `data/llm_cache/` — every model answer.
- `results/` — replay output per policy, `scorecard.json` and `trades.csv`.
- `logs/` — the live paper log, live trades and morning notes.
- `ask/` — the Ask Pervigil worker.
- `docs/` — the public site.
