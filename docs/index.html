      Every rule here was replayed in advance by the same code that scores the agent, so the numbers are the real backtest, not an estimate. A rule that wins was picked after seeing these 55 nights, so it is not proven on new ones. The same caution applies to the agent's own earnings rule.

      How the watch works

      The same five steps, every six hours, for as long as the market is closed.

      1. Sense

        Each stock's move since the close, sized against its normal day, plus Bitcoin, earnings and news.

      2. Decide

        Qwen sets a target per stock with a one-sentence reason. Staying out is allowed.

      3. Risk layer

        Hard limits it cannot override: 20% per stock, 60% in total, stop-losses, no late entries.

      4. Execute

        Paper fills at Bitget prices with fees and slippage, mirrored as orders on Bitget's demo exchange.

      5. Flatten

        Everything is closed 15 minutes after the open, and a morning note is written.

      How it got here

      The first version lost money. The earlier results stay on this page because a scorecard that only shows the final run is not a scorecard. Every run is in the results folder.

      2. Run 2

        After fixing a data bug

        The earnings calendar was one night early, so on the night a company reported, the agent was told there was no news. Fixed, with no change to its instructions.

        −0.85%→+0.27%
      3. Run 3 · current

        After adding one rule

        On a night a company has just reported earnings, do not bet against the move. The whole gain comes from four earnings nights, and the rule was written after seeing them, so it is not yet proven on new nights.

        +0.27%→+5.80%
